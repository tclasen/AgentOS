# AgentOS

AgentOS helps an AI agent set up a small organization tailored to your project, led by a Director and Chief of Staff.

Open your project in an AI agent and paste:

> Install AgentOS into this project using the latest version on the main branch of https://github.com/tclasen/AgentOS. Read `bundle/start.md` and follow its instructions. Inspect the project, ask any necessary questions, and get my approval for the proposed setup before changing files.

The [installer guide](bundle/start.md) walks the agent through discovery, setup, validation, and handoff. The [knowledge graph](bundle/index.md) contains the supporting instructions in Markdown.
