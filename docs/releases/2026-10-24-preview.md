# AgentOS preview — 2026-10-24

This release packages the existing installer bundle and optional Python tools for supervised use. It adds a clear entry point, a reproducible bundle identity and current local verification evidence. It changes no installer contracts or qualification criteria. It is not a claim of unattended installation reliability.

## What is usable

The [README](../../README.md) contains the installation request. An agent with repository reading/editing tools follows [start.md](../../bundle/start.md), discovers the target read-only, selects the required and relevant conditional components, obtains your approval for exact paths, implements, checks the selected obligations and hands over to the Director. There is no automatic installation executable. Python is optional for the Markdown workflow; the local helpers require Python 3.9+. Native trial controls require a POSIX runtime, authenticated Codex and an operator-created disposable sandbox, as described in the [tool guide](../../tools/README.md).

The default selection has ten mandatory components. Optional components add capabilities only when relevant; source selection does not authorize their effects. Fresh sessions and available delegation depend on the actual host runtime. Review generated instructions against selected original contracts, especially when using a weaker model. A plausible installer report is insufficient to accept an installation.

## Verify the bundle

From this source checkout:

```sh
python3 tools/qualification.py graph bundle
python3 tools/qualification.py select bundle
python3 tools/qualification.py identity bundle --verify docs/releases/2026-10-24-source.json
```

The [source manifest](2026-10-24-source.json) binds every regular file under `bundle/` by path, SHA-256 and byte length. It excludes tools, documentation and Git metadata. Identity equality detects source changes; it grants no trust, comprehension or installation authority. Keep the original approved manifest during continuation rather than replacing it with regenerated current bytes. The helper does not write into a target project.

Release candidate, checks, independent approval and remote-main delivery are tracked in [TASK210](../agent-records/portfolio-2026-10-24/TASK-000210.md) and [RUN205](../agent-records/portfolio-2026-10-24/RUN-000205.md). Local checkout retirement is performed separately after remote preservation and verification; it does not retire the GitHub source or erase historical reports.
