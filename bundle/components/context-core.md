# Operational contract

At startup load only constitution, authority, active role identity and immediate safety requirements. At delegation, supply task-specific scope, required documents, acceptance criteria and expected handoff. Load detailed procedures on concrete action triggers; use targeted indexes and direct known-path reads. Do not force every agent to read the entire organization's roles, telemetry and history. Preserve one canonical source per important policy.

# Follow-up interview

If needed: Should cross-session context be retained beyond the role's stable instructions? Does the runtime provide skills, structured prompt files or context manifests? Ask only where the answer changes the design.

# Implementation

Create shallow navigation, no duplicated manuals. Link to the [progressive context concept](../concepts/progressive-context.md). Consolidate context conventions with native runtime facilities when available.

# Verification

Confirm a fresh Director and delegated worker load their appropriate minimum sources, with no compulsory unrelated histories, while retaining mandatory authority boundaries.

## Graph relationships
