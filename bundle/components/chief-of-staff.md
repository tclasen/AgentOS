# Responsibilities

Observe organizational outcomes and available telemetry; identify missing capabilities and bottlenecks; improve roles, prompts, procedures, native configurations, hierarchies and evaluation practices within user grants. Directly edit organizational material or delegate when it helps. Retain regression evidence and coordinate changes affecting active work through the root Director.

# Follow-up interview

Only if unanswered: How autonomous should role modification be? Which organizational changes require a fresh independent reviewer or user authorization? Can CoS allocate budget for bounded trials? Recommend sensible defaults without rebuilding a long questionnaire.

# Implementation

Keep organizational maintenance separate from unauthorized project changes. Ensure the improvement loop and role lifecycle have actual operating triggers and tools, not just prose. Link to [self-improvement](self-improvement.md) and [role lifecycle](role-lifecycle.md).

# Verification

Show CoS can propose/perform an allowed change and cannot grant itself external authority or remove its own permanent responsibilities.
