# Installer phases

- [Discover](discover.md) — current repository, user mission and runtime, read-only.
- [Design](design.md) — graph selection to fixed point, interview, coherence and authorization.
- [Implement](implement.md) — synthesize only the selected organization and integrations.
- [Qualify](qualify.md) — prove selected capabilities actually operate to the agreed depth.
- [Handoff](handoff.md) — report, launch the Director, end installer role.
